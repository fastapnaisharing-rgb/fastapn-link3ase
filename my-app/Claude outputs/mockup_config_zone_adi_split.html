กติกาที่เสนอ (ขอให้ยืนยัน)

1. เปิด Popup แล้วมี 2 คอลัมน์ Dr./Cr. พร้อมแถวเริ่มต้นจากกรอบ Debit/Credit ที่กรอกอยู่ — เพิ่มแถวสาขาได้ทั้งสองฝั่ง
2. ยอดที่ใช้แบ่ง = ค่าในช่อง Default (Vat) (ไม่แก้เลข = Vat ที่คำนวณ, แก้เลข = ยอดที่แก้)
3. ผลรวมฝั่ง Dr. ต้องเท่ากับฝั่ง Cr. และเท่ากับยอดที่ตัด จึงกด "ตกลง" ได้
4. หัวเฉลี่ย (BU ของสาขานั้น % ≠ 100) และยอดเป็น + : แตกแถวส่วนเคลมได้ + ส่วนต่างภาษี 45700 / 63050000 / 999999 ที่ฝั่ง Dr.  (ยอดติดลบ → สลับไปฝั่ง Cr. ตาม Logic Average-IB เดิม)
5. เมื่อกด "ตกลง": Simple = No/No/No, ADI Badge = Manual-ADJ, ตาราง Upload ADI ใช้แถวตามที่ตั้งใน Popup
