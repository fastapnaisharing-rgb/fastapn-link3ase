แท็บ "แนบไฟล์ / ลากไฟล์" กับ "วาง Text จาก Excel / Notepad"

กดสลับแท็บได้จริงในทุกแบบ | ตัวเนื้อหาข้างล่าง (กล่องลากไฟล์ / ช่องวางข้อความ) ใช้ของเดิม เปลี่ยนแค่ตัวสลับ

แบบ A · แท็บขีดเส้นใต้
ลากไฟล์มาวาง หรือคลิกเพื่อเลือกไฟล์รองรับ TB (.out), Input Summary (.out) และ Simple Report (.xlsx)
หรือกด Ctrl+V เพื่อวางข้อมูลจากคลิปบอร์ดโดยตรง

เรียบ ดูเหมือนแท็บเมนูหลัก (Dashboard / Upload File) ที่มีอยู่ ใช้พื้นที่น้อยที่สุด

แบบ B · Segmented (สวิตช์แบบแคปซูล)
ลากไฟล์มาวาง หรือคลิกเพื่อเลือกไฟล์ระบบตรวจชนิดไฟล์ให้อัตโนมัติ

ชัดว่าเลือกได้ทีละอย่าง ชื่อสั้น เหมาะกับพื้นที่แคบ แต่ดูเป็นสวิตช์มากกว่าแท็บ

แบบ C · แท็บแบบแฟ้ม (ติดกับกรอบเนื้อหา)
ลากไฟล์มาวาง หรือคลิกเพื่อเลือกไฟล์รองรับ TB (.out), Input Summary (.out) และ Simple Report (.xlsx)

แท็บเชื่อมกับกรอบเนื้อหา เห็นชัดว่าเนื้อหาข้างล่างเป็นของแท็บไหน

แบบ D · แท็บแบบการ์ด มีคำอธิบายใต้ชื่อ
ลากไฟล์มาวาง หรือคลิกเพื่อเลือกไฟล์หรือกด Ctrl+V เพื่อวางจากคลิปบอร์ด

บอกชัดว่าแต่ละแท็บทำอะไร เหมาะถ้าผู้ใช้ใหม่ยังไม่คุ้น แต่สูงกว่าแบบอื่น
